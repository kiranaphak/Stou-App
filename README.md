# ค้นหาหลักสูตร มสธ. ที่เหมาะกับคุณใน 5 นาที
**เว็บแอปพลิเคชันแนะนำเส้นทางการเรียนและสาขาวิชา มหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.)**

---

## 📌 วัตถุประสงค์
แอปพลิเคชันนี้ออกแบบมาเพื่อให้ผู้เข้าชมงานนิทรรศการ หรือผู้สนใจเรียน มสธ. ผ่าน QR Code บนสมาร์ตโฟน สามารถตอบคำถามสั้น ๆ เพียง 6 ข้อ ภายในเวลาไม่เกิน 5 นาที เพื่อค้นหา:
1. **เส้นทางการเรียนรู้ที่เหมาะสมกับเป้าหมายชีวิต** (3 กลุ่ม: นักพัฒนาความก้าวหน้าในอาชีพ, ผู้วางรากฐานสู่ปริญญา, นัก Upskill / Reskill)
2. **3 กลุ่มสาขาวิชา มสธ. ที่สอดคล้องกับความสนใจ** (จับคู่จาก 12 สาขาวิชาของ มสธ.)

---

## ⚙️ สถาปัตยกรรมและการทำงาน (Architecture & Privacy)
- **Zero-Storage for Quiz (ความเป็นส่วนตัวสูง)**: คำถามและคำตอบของแบบทดสอบถูกประมวลผลบนหน่วยความจำของเว็บเบราว์เซอร์ (Client-side memory) ไม่มีการบันทึกลงในฐานข้อมูล, LocalStorage หรือส่งเข้าภายนอก
- **Rule-based Scoring & Eligibility Gate (เกณฑ์คุณสมบัติ)**:
  - คำนวณคะแนนตามน้ำหนักของแต่ละตัวเลือก (`careerScore`, `degreeScore`, `upskillScore`)
  - ตรวจสอบคุณสมบัติการศึกษา (Eligibility Gate): หากผู้ใช้จบต่ำกว่าปริญญาตรี ระบบจะไม่แนะนำเส้นทางระดับบัณฑิตศึกษา (ปริญญาโท-เอก) และจะซ่อนปุ่มหลักสูตรปริญญาโท
  - ตัดสินผลคะแนนเสมอ (Tie-breaking): 1. เป้าหมายการเรียน (ข้อ 4), 2. ระดับการศึกษา (ข้อ 2), 3. เวลาในการเรียน (ข้อ 3)
- **PDPA Compliant Advisory Request**: มีฟอร์มขอให้เจ้าหน้าที่ติดต่อกลับที่ปลอดภัย ข้อมูลถูกส่งผ่าน Server-side API `POST /api/leads` และไม่มีการติ๊ก Checkbox ยินยอมไว้ล่วงหน้า (No pre-ticked consent)

## 🔗 การแก้ไขและอัปเดตลิงก์ภายนอก (External URLs Configuration)
ลิงก์หลักทั้งหมดถูกรวมศูนย์ไว้ที่ไฟล์ `/src/data/config.ts` เพื่อความสะดวกในการดูแลรักษา:

```typescript
// /src/data/config.ts

// 1. ลิงก์ข้อมูลหลักสูตรปริญญาตรี
export const BACHELOR_URL = 'https://www.stou.ac.th/main/curriculums/bachelor/';

// 2. ลิงก์ข้อมูลหลักสูตรระดับบัณฑิตศึกษา (ปริญญาโท-เอก)
export const GRADUATE_URL = 'https://gs.stou.ac.th/';

// 3. ลิงก์โครงการสัมฤทธิบัตร มสธ. (เรียนรายชุดวิชา/สะสมหน่วยกิต)
export const SUMRIT_URL = 'https://www.stou.ac.th/study/sumrit/';

// 4. ลิงก์ฟอร์มขอรับคำปรึกษาจากเจ้าหน้าที่ มสธ.
export const LEAD_FORM_URL = '#advisory';

// 5. ลิงก์ระบบรับสมัครออนไลน์ มสธ.
export const STOU_ADMISSION_URL = 'https://apply.stou.ac.th';
```
